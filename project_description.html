1. Introduction

Code search is a critical task for software developer productivity, enabling efficient retrieval of relevant code snippets from large repositories using natural language queries. While English-centric code search has seen significant advances through pre-trained models, cross-lingual code search, where queries are posed in non-English languages, remains substantially underexplored. This is particularly problematic for Indonesian developers, who represent one of the fastest-growing developer communities globally yet face a significant linguistic barrier when searching through predominantly English code repositories.

This project addresses the challenge of cross-lingual code retrieval: searching English Python code snippets using Indonesian natural language queries. The core difficulty lies in bridging the vocabulary gap between Indonesian queries (e.g., "cara simpan data ke database") and English programming identifiers (e.g., for, def, commit()). Simple machine translation often fails to capture functional equivalence, and monolingual embedding models cannot effectively handle cross-lingual semantics.

2. Research Objectives

This project investigates four key research questions:

  1. How does Technical Query Expansion (TQE) improve retrieval performance for Indonesian code search?
  2. Does cross-encoder re-ranking improve precision after first-stage dense retrieval?
  3. What is the magnitude of the cross-lingual gap between English and Indonesian queries, and can this approach reduce it?
  4. Which combination of TQE methods and re-ranking yields optimal performance?

3. Methodology

First-Stage Dense Retrieval with Multilingual E5 (mE5). We leverage the Multilingual E5 embedding model (intfloat/multilingual-e5-base, 278M parameters) to encode both Indonesian queries and English code snippets into a shared 768-dimensional semantic vector space. This enables cross-lingual matching via cosine similarity without explicit translation, providing robustness against translation noise.

Technical Query Expansion (TQE) via LLMs. To bridge the vocabulary mismatch, we apply query expansion using HyDE (Hypothetical Document Embeddings), an LLM generates a hypothetical English code snippet from the Indonesian query, which is then used for retrieval. Experiments are conducted with LLaMa3 model.

Second-Stage Cross-Encoder Re-ranking. After retrieving the top-K candidates, a cross-encoder model jointly processes query-code pairs to capture fine-grained token-level interactions that dual-encoders miss. We evaluate multilingual cross-encoders including mmarco-mMiniLMv2-L12, with Reciprocal Rank Fusion (RRF) for combining retrieval signals.

4. Experimental Setup

The approach is evaluated on the CoSQA dataset (20,204 human-annotated Python code-query pairs) with 500 queries being translated to Indonesian. Four configurations are tested: Baseline (mE5 only), TQE-Only (mE5 + Query Expansion), Rerank-Only (mE5 + Cross-Encoder), and Full Pipeline (mE5 + TQE + Cross-Encoder). Performance is measured using nDCG@10, MAP@10, Recall@10, and MRR.
