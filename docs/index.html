01 Abstract

Penelitian ini mengeksplorasi efektivitas model Multilingual E5 (mE5) dalam menjembatani kesenjangan performa (cross-lingual gap) pada tugas pencarian kode sumber menggunakan Bahasa Indonesia. Saya mengusulkan arsitektur Two-Stage Pipeline yang mengintegrasikan Technical Query Expansion (TQE) HyDE dan MiniLM Cross-Encoder. Hasil pengujian pada korpus CoSQA menunjukkan peningkatan nDCG@10 sebesar +0.056, yang mereduksi 66.7% dari total kesenjangan performa dibandingkan kueri Inggris asli.

02 Problem Definition

Pencarian kode lintas bahasa (Indonesia ke Python) menghadapi tantangan unik berupa mismatch semantik. Istilah teknis seringkali mengalami korupsi makna saat proses translasi atau encoding langsung.

  • Baseline Gap: Penurunan nDCG@10 sebesar $0.302 - 0.218 = 0.084$ pada model mE5-base tanpa optimasi.
  • Vocabulary Mismatch: Token teknis penting berubah menjadi kata umum (e.g., fits → cocok).
  • Structural Awareness: Model bi-encoder standar gagal menangkap dependensi token struktural yang kompleks.

03 Tinjauan Pustaka & Dataset

Dataset CoSQA (Huang et al., 2021)

Code Search and Question Answering (CoSQA) adalah dataset yang terdiri dari 20.604 pasangan kueri bahasa alami dan snippet kode Python. Dataset ini dikumpulkan dari log pencarian Microsoft Bing, mencerminkan kebutuhan nyata developer.

04 Konfigurasi Eksperimen

Sistem diimplementasikan menggunakan framework modern untuk memastikan skalabilitas dan reproduksibilitas hasil.

System Settings
  • Embedding Model: intfloat/multilingual-e5-base (768 dimensi).
  • Reranker Model: cross-encoder/ms-marco-MiniLM-L-6-v2.
  • Expansion Engine: Google Gemini Flash (Zero-shot HyDE).
  • Retriever Index: FAISS (Inner Product similarity).
  • Hardware: CPU-based inference.

05 System Architecture

Tahap 0: Technical Query Expansion (HyDE)

HyDE memetakan kueri zero-shot ke ruang dokumen semu menggunakan probabilitas token LLM:

$$P(Y | X) = \prod_{t=1}^{T} P(y_t | y_{<t}, X)$$

Tahap 1: Dense Retrieval (mE5)

Menggunakan arsitektur Bi-Encoder untuk mengencode kueri ekspansi dan dokumen ke dalam manifold semantik yang sama menggunakan model multilingual-e5-base.

Tahap 2: Cross-Encoder Reranking (MiniLM)

Memproses pasangan (kueri, kode) secara bersamaan untuk menangkap Joint Attention antar token, meminimalkan false positives dari tahap retrieval.

07 Discussion: Paradoks Embedding Drift

Analisis Pearson menunjukkan korelasi rendah ($r \approx 0.037$) antara Embedding Drift dengan performa retrieval. Hal ini membuktikan bahwa kedekatan kueri ke distribusi kode jauh lebih penting daripada kedekatan linguistik ke kueri Inggris.
